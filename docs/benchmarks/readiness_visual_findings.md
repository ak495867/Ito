# Benchmark Visual Findings

The reviewed p99 chart is readable and contains four distinct adapter series, a jitter axis in nanoseconds, a p99 latency axis in nanoseconds, and a complete legend. The plotted curves rise monotonically with simulated jitter. `broker-b-sim` has the highest p99 values, while `exchange-a-sim` has the lowest values in every tested scenario. The chart is a regression visualization of virtual timestamps and does not represent measured production network behavior.
